# Reporting a security vulnerability

Use GitHub Private Vulnerability Reporting to report HyperMusic vulnerabilities through the repository's [Security advisories page](https://github.com/SachinYedav/hypermusic/security/advisories). Select **Report a vulnerability** and include the affected version and a description of the issue. The repository owner must enable the feature for the button to appear.

Keep vulnerability details and sensitive logs out of public issues. Use public issues for ordinary bugs and feature requests.
